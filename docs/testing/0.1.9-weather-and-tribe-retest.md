# 0.1.9 weather, fishing and tribe acceptance

User acceptance update, 2026-09-21: after installing 0.1.9, the user reported
"weather options work perfect". Basic weather-control gameplay is user-confirmed.
The report does not individually establish save/reload, world changes, special
event priority or FPS results; those detailed checks remain unconfirmed.

The previous 0.1.8 fishing/Easy Catch and recruit reroll reports were successful.
Other 0.1.9 controls and work-speed comparisons still need testing. The checklist
below retains the detailed acceptance procedure.

1. Confirm the header is HutchASKA 0.1.9, the menu fills the game-window height
   with small margins, and Close/F8 work. Player Harvesting Speed should be in
   Fishing & Foraging.
2. In World, select Rain and wait for the status to say applied. Then choose
   Clear Skies and Normal Forecast. Check Fog, Overcast and Blizzard if wanted.
   A missing ordinary asset should report unavailable; scripted special weather
   should pause the override rather than be replaced. Seasonal climate remains.
3. Check Normal, Reset All, configuration reload, freeze/unfreeze time and changing
   worlds. Forced weather should not carry across worlds/restarts. Ground wetness
   and snow can remain and clear naturally. Normal should not move the clock or
   reroll the forecast. Check one save/reload while selected: ordinary world
   effects may save, but the forced selection must restart at Normal.
4. With bait equipped, check fishing still catches normally. Rare weight should
   offer Normal, 20x, 30x, 40x and 50x; bite speed stays Normal/2x/4x. These are
   relative weights for eligible rare fish, not guaranteed percentages. Missing
   biome/season/bait eligibility is not bypassed. Return to Normal and check it
   survives configuration reload.
5. Follow tribe-work-skill-retest.md for separate player/tribe skill gains, tribe
   construction, harvest and ground movement. Compare work/progress per action
   at 1x and maximum using equivalent targets; faster animations are not promised.
   Player build speed remains an unresolved user comparison despite logged work
   differences at 2x and 4x; verify that ordinary building continues to finish.
6. Check FPS and logs after several minutes. Weather logs only selection/application
   transitions; work and skill diagnostics are bounded. No recurring exceptions
   or rapid repeated error logs should appear.

Keep mushroom acceleration, expanded terrain leveling and the previously
withdrawn item-decay hooks unavailable. No save or achievement counter edits are
part of this update.
