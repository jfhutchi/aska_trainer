# HutchASKA 0.1.13 farm-plot retest

On 2026-09-22, the user reported that a farm plot built with all trainer
features off, while attempting another plot with Free Building on crashed ASKA.
The game logs reported a null farm crop grid during farm activation through
`BuildPart.CheckSupplies`.

Version 0.1.13 leaves farm plots on native material checks while preserving
Free Building for other eligible structures. After installing 0.1.13, the user
confirmed that farm-plot construction works. This is in-game acceptance of the
farm-plot crash fix; it does not establish the state of any plot saved after a
prior crash.
