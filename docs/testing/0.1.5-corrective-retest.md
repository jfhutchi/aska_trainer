# 0.1.5 corrective retest

## User and runtime evidence

- User reports movement still unchanged in 0.1.4. Twelve bounded samples show
  local command dispatch but zero boosted commands. The external-control
  rejection accounts for normal grounded movement; root-motion share is zero.
- Native PlayerDrive requires hasExternalControl=true before it sends ordinary
  movement commands. Target matching clears the permission and restores it when
  matching ends. The previous interpretation was reversed. The new shared core
  predicate requires player-input permission and retains all special-movement
  exclusions.
- Build Speed startup failed with AmbiguousMatchException. The derived build
  session's Agent property returns PlayerInteractionAgent while the base Agent
  returns IInteractionAgent. Declared-property lookup selects the actual member.
- The user extended the first terrain side to 20 tiles, then began the second
  side and the game crashed. 10x10 was explicitly not tried. Windows recorded
  a native access violation in GameAssembly.dll at RVA 0x109FFF7. The matching
  dump contains preview resizing/update frames and a 17x20 (340-cell) grid.
  Both normal and large templates use the same 256-bit preview state. Its native
  UpdateGridValidityOnNetwork loops over the full grid with no 256-cell bound,
  writing past a stack-local BitSet256 into saved registers and the return
  address at indices 320-383. The final structure's larger capacity did not
  protect this shared preview. This is not a managed exception the host can catch.
- Expanded leveling is withdrawn in 0.1.5: no Harmony placement hooks, preview
  clones or larger-size buttons remain. ProbeCompatibility always reports the
  reason and TryEnable returns false, including configuration restoration.
- The axe samples show matching Chop/ChopGround actions and animator speed 4.0.
  This proves application on those sampled animations, not pickaxe, completion
  timing or every harvesting path. Instant Summon was user-confirmed in 0.1.3.

## Automated verification

The combined Release build passes with zero warnings/errors and 175 core tests
pass, including 11 new movement eligibility cases. The GUI interop gate checks
78 reachable managed methods. Terrain containment also receives a built-assembly
inspection to ensure the withdrawn implementation contains no native hook calls.
Native retesting remains separate from these automated results.
