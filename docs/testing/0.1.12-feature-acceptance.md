# 0.1.12 additional feature acceptance

User acceptance update: 2026-09-21, HutchASKA 0.1.12 on ASKA Steam build 25440748.

The user reported that all of the following installed features work in the tested single-player game:

1. Tribe Skill Gain across normal earned-skill activities.
2. Tribe Harvest Speed for gathering and eligible tool work.
3. Infinite Fuel for owned campfires and standing torches.
4. Free Repairs while retaining normal repair work.
5. Ignore Crafting Materials for unlocked local-player recipes.
6. Retain Items on Use while preserving normal consumable effects.
7. Freeze Time, minus/plus one hour, and Game Speed.
8. Player and tribe protection and needs controls, including healing and needs restoration.
9. Give Item and Give Stack through the runtime item catalog.

This report closes the previously recorded basic-effect acceptance gaps for these controls. It does not independently establish every boundary case, such as every item definition, save/reload state, native cap, midnight rejection, special weather interaction, departed-villager ownership change, or full enable/disable matrix. Those limitations remain part of the feature contracts rather than evidence that the reported effects failed.

Combined with the separate 0.1.12 transition acceptance, the current user-confirmed set includes menu readability and lifecycle, player and tribe speed/work controls, skill gains, fishing assists and Rare Fish Anywhere, recruit trait reroll, Instant Summon, weather, construction/repair material waivers, fuel, item retention/give actions, protection/needs, and world-time controls.
