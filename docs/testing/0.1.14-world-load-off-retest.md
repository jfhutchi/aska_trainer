# HutchASKA 0.1.14 world-load retest

Version 0.1.14 changes the 0.1.12 transition behavior at the user's request:
trainer options start off in every loaded world, even when ASKA remains open.
Previously enabled gameplay features are disabled when leaving a confirmed
single-player world and are not rearmed on return. Old restore-on-launch and
enabled-state config entries are cleared; saved multiplier presets remain
available but inactive. Easy Catch and Rare Fish Anywhere reset to off.

Manual acceptance is pending:

1. Start ASKA and load a world. Confirm the F8 gameplay toggles are off.
2. Enable No Thirst (Tribe), Free Building, and Easy Catch, then return to the
   main menu.
3. Load a world without quitting ASKA. Confirm all three options are off and Free
   Building no longer waives materials until explicitly enabled.
4. Enable No Thirst (Tribe) in that world and check a villager's Water value
   after a few seconds. This last check is separate from the world-load change.
